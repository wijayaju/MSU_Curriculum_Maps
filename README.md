## Navigating Through the Repository
To get to our final product for this semester, head to the folder titled "api". In there is a file titled `API_Demo.ipynb` where you can run through a demo of our api. Data should already be present in the folder for everything to run properly.

In the folder titled "webapi" is a look into the start of a possible UI for a directed graph by major. 

In the folder titled "old_work" are some initial jupyter notebooks that were developed throughout the semester. Those notebooks go through some of the logic and thought processes we had throughout the course of the semester that led us to our final solution.

## Project Overview  
This project will focus on transforming the cleaned curriculum data into a format compatible with the Curricular Analytics platform (https://curricularanalytics.org) and then extending the platform to visualize MSU data.

---

## Goals  
- Familiarize ourselves with the work that has been done by previous teams so that we can understand how the API functions, and what data is being scraped previously and how 

- Become FIRPA compliant 
- Develop a proficiency in Julia, so that we can complete the project 
- Figure out how to obtain the course data (probably from MSU SIS?) 
- Familiarize ourselves with the Curricular Analytics platform, and how data needs to be inputted into this platform 
- Produce a working prototype and analysis pipeline 
- Transform the data generated by the previous Python API into Julia so that it can be input into the Curricular Analytics API 
- Adapt the project to fulfill the requirements for CMSE 495 and CMSE 402 
- Set-up a virtual environment that works with Python and Julia on any machine so that we our code and analysis are reproducible.

## Research Questions  
- How can we effectively translate MSU curriculum data into Curricular Analytics format?
- What insights can we gain from the platofrm's built-in metrics and visualizations?
- How do structural features of the curriculum relate to student success indicators such as grades and withdrawl rates?
- Can we identify opportunities to streamline the curriculum or improve alignment with learning goals?
